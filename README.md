## 👨‍💻 About Me

Hi! I'm **Youssef Afroto**, an IT student from Egypt passionate about cybersecurity, ethical hacking, and software development.

My journey focuses on understanding how applications, networks, operating systems, and security controls work — and how to identify and responsibly validate security weaknesses.

I focus on two cybersecurity domains:

- 🌐 **Junior Web Penetration Tester** — Web application security, vulnerability discovery, manual testing, and security assessment.
- 🎯 **Junior Red Team Operator** — Linux security, reconnaissance, enumeration, and foundational attack-and-defense techniques in authorized environments.

Outside cybersecurity, I build applications, explore automation, and develop my programming skills. I believe that understanding how software is built makes me better at understanding how it can fail.

### ⚡ What I'm Working Toward

- Improving my web penetration testing methodology through hands-on labs.
- Developing my knowledge of internal networks, Active Directory, and Windows environments.
- Practicing Linux privilege escalation and security enumeration.
- Building cybersecurity tools and practical software projects.
- Strengthening my networking fundamentals and red team methodology.

> **Think like a developer. Test like an attacker. Learn like a researcher.**
